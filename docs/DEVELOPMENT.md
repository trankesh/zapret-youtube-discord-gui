# Разработка

Приложение написано на C# 5 / WPF и собирается для Windows x64, .NET Framework 4.8. Используется установленный системный `csc.exe`; npm и отдельный SDK не нужны.

## Локальная сборка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Выход: `build\Zapret.exe`. Версия берётся только из `VERSION`. Шрифт, иконка, XAML, конфигурация runtime, скрипт управления DNS и официальный архив Flowseal встраиваются в EXE. Профиль пользователя не встраивается.

## Проверки

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\release.ps1 -RunNetworkTests
```

- Features: временные файлы hosts, точное восстановление, BOM/кириллица, устаревший предпросмотр, ZIP traversal, хеш встроенного набора, его стратегии, миграция профиля и модель автозапуска с поддельным Планировщиком.
- DNS: сценарии применения/отката, IPv4/IPv6, DHCP, частичная ошибка, отключённый протокол и системные политики. Сетевые команды заменены тестовыми реализациями.
- Task Scheduler: проверка XML через `TASK_VALIDATE_ONLY`, без регистрации задачи; отдельное чтение состояния существующего автозапуска без изменений.
- Self-test: разбор аргументов стратегий, порты, IPSet на временных копиях, ответы HTTP/curl через `127.0.0.1`, отмена.
- Preview: отрисовка экранов WPF, масштабы 100/150%, открытый список стратегий и hit-test его шапки, шаги мастера, блокировка UI при переборе.
- Privacy: проверка публикуемых файлов на локальные пути, имя профиля сборщика, адреса почты и секреты; проверка состава ZIP по разрешённому списку.

Автоматические проверки не запускают winws, не изменяют системные hosts/DNS, службы или автозапуск. Нативные проверки Планировщика и loopback требуют обычного Windows-сеанса с разрешённым COM/localhost. Реальные UAC, драйвер, перезагрузка и сетевой обход проверяются вручную; автоматические проверки их не заменяют.

Для отдельных отрисовок:

```powershell
Start-Process .\build\Zapret.exe -ArgumentList '--preview' -Wait
```

Изображения сохраняются в `artifacts` уровнем выше EXE. Preview использует отдельные данные и не запускает обход. Не публикуйте экран настройки внешнего набора с путём реального пользователя.

## Исходники

| Файл | Роль |
| --- | --- |
| `src/App.cs`, `src/Shell.xaml` | Главное окно, выбор стратегии, тесты и настройки |
| `src/Shell.Setup.cs`, `src/Shell.Safety.cs` | Мастер, потеря набора, блокировка перебора |
| `src/Shell.Desktop.cs`, `src/AutoStart.cs` | Трей, повышение прав и защищённый автозапуск |
| `src/HostsUpdate.cs`, `src/SecureDns.cs`, `src/DnsControl.ps1` | Hosts и DNS с резервными копиями и откатом |
| `src/Core.cs`, `src/StandardTest.cs` | Набор, процесс/служба и проверки сети |
| `src/MouseScrolling.cs`, `src/GestureMath.cs` | Перетаскивание страниц и жесты списка |

Сохранённые аргументы службы обновляются после её переустановки. Доменные списки перечитываются при перезапуске. TCP timestamps включаются при запуске так же, как в исходном наборе; остановка не откатывает эту системную настройку.

Исходники Cygwin/WinDivert скачиваются с проверкой закреплённых SHA-256 скриптом `prepare-third-party-sources.ps1`. Он создаёт отдельный архив для публикации рядом с бинарными файлами. Он не исполняет загруженный код.
