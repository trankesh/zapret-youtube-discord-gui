# Выпуск версии

Текущая стабильная версия: **1.0.0**.

## Сборка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\release.ps1 -RunNetworkTests
```

Версия задаётся в `VERSION`. Скрипт использует новый staging-каталог, запускает проверки, отрисовывает интерфейс, проверяет приватность и формирует в `dist`:

- самостоятельный portable EXE;
- полный ZIP с документацией, скриншотами и лицензиями;
- архив исходников сторонних WinDivert/Cygwin с закреплёнными хешами;
- `SHA256SUMS.txt` для всех трёх файлов.

Профиль, журналы, резервные копии и результаты тестов не входят в поставку. Текущий пользовательский профиль не удаляется и не сбрасывается. EXE не подписан сертификатом издателя.

## Публикация

GitHub Actions собирает и проверяет каждый push / pull request. Для выпуска сопровождающий обновляет `VERSION` и отправляет в `main` коммит, сообщение которого начинается с `[release]`. После успешной сборки отдельное задание с правом `contents: write` создаёт тег `v<version>` на проверенном коммите и GitHub Release с файлами из той же сборки. Версии с суффиксом `-rc.*` публикуются как prerelease. Существующий тег/релиз автоматически не перезаписывается.

Обычные коммиты и pull request не публикуют релиз. Токен предоставляется GitHub только на время задания, собственные секреты для сборки не требуются.

## Проверки на обычном Windows

Автоматические проверки не заменяют ручную проверку реального драйвера/службы, подключения к провайдеру, UAC и автозапуска после входа. Текущее состояние автоматических проверок видно в Actions; неисследованные сценарии не следует описывать как гарантированно работающие.

Контрольный список для сопровождающих:

- запуск одного EXE без внешнего config, мастер и перенос старого профиля;
- запуск/остановку, потерю набора, завершение и отмену перебора;
- автозапуск после входа в Windows и работу трея;
- hosts/IPSet/DNS, точный откат и работу службы на тестовом компьютере;
- происхождение бинарных зависимостей и наличие их исходников рядом с релизом.

Сведения о компонентах и источниках — в `THIRD-PARTY-NOTICES.md`, `assets/bundle/NOTICE.md` и `licenses/SOURCES.md`.
