# Запуск одного EXE

1. Скачай новый Zapret.exe. Его можно положить на рабочий стол или в удобную папку.
2. Полностью выйди из прежней версии через меню значка в трее.
3. Открой EXE и подтверди права администратора.
4. Выбери папку Flowseal или встроенный набор. Остальные шаги мастера можно пропустить.
5. На главной выбери стратегию и нажми «Подключить». Если не знаешь, какую выбрать,
   открой автоподбор. Во время подбора доступна только его отмена.

Нужны Windows x64 и .NET Framework 4.8. Внешний config не обязателен. Установщик
больше не выпускается. Полный ZIP содержит тот же EXE, инструкции и лицензии.

## Где находятся настройки

По умолчанию — `%LocalAppData%\ZapretDesktop`. Здесь находятся настройки, журнал,
встроенные наборы и резервные копии. Открыть каталог можно через «Настройки →
Приложение → Папка данных». Перемещение EXE не меняет этот профиль.

Для перехода со старой папки data сначала запусти новый EXE рядом с ней. Если в
AppData ещё нет профиля, данные будут скопированы туда. Исходник не удаляется;
существующий профиль AppData не перезаписывается. Внешние наборы Flowseal остаются
на прежнем месте: не удаляй их после переноса программы.

Для хранения профиля на флешке вместе с EXE можно создать рядом пустой файл
portable.mode. Тогда папку data нужно переносить вместе с программой.

## Если папка Flowseal пропала

Программа проверяет выбранную папку при запуске и во время работы. При удалении,
перемещении или отключении диска появится экран выбора набора. Выбери новое
расположение либо встроенный набор. Пропустить выбор нельзя. Если папка пропала
во время подбора, он отменяется; полученные результаты сохраняются по возможности.

## Автозапуск и обновление

В настройках включи «Запускать интерфейс с Windows». Для запуска в трее включи
«Запускать свёрнутым». Задача Планировщика использует защищённую копию EXE с
повышенными правами, без повторного UAC при входе в учётную запись администратора.

Перед обновлением полностью выйди из приложения через трей. Замени EXE и открой
новую версию вручную с UAC: включённый автозапуск обновится, профиль сохранится.
Пока идёт подбор, сначала нажми «Отменить подбор» и дождись завершения отмены.

Если раньше использовался установщик, его можно удалить через настройки Windows
после полного выхода из GUI. Профиль AppData сохраняется. Новая standalone-версия
использует его же. Удаление GUI не откатывает hosts/DNS и не удаляет отдельную службу
Zapret. Для DNS доступен откат в приложении; отдельную службу нужно удалить через
его настройки. Кнопки восстановления hosts в GUI нет.

Версия этой сборки — 1.0.1.
