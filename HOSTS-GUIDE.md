# Как обновить hosts

В мастере и настройках есть переключатель **«Адреса Secure DNS в hosts»**. Он добавляет официальные IPv4/IPv6 адреса Cloudflare, Google, Quad9, AdGuard и OpenDNS, включая `one.one.one.one`, `dns.google` и `doh.opendns.com`. Изменения видны в предпросмотре и записываются вместе с обновлением hosts, с общей резервной копией. Выключение переключателя само по себе файл не меняет: чтобы убрать эти записи из блока приложения, обновите hosts ещё раз.

Это помогает получить IP DNS-сервиса без обычного DNS, но не включает шифрование и не обходит блокировку самого IP. Для шифрования откройте **«Настройки → Защищённый DNS»** или необязательный третий шаг мастера. Там есть выбор провайдера, инструкция и откат изменения Windows DNS.

1. Откройте `Zapret.exe` и подтвердите запрос Windows на права администратора. При отказе приложение закроется.
2. В мастере первого запуска перейдите к шагу **«Hosts и IPSet»**. Позже этот же раздел доступен в **«Настройки»**.
3. Нажмите **«Проверить актуальность»**. Если написано «актуален», hosts менять не нужно.
4. Если есть изменения, можно открыть **«Посмотреть изменения hosts»**. Нажмите **«Обновить hosts»**: приложение повторно проверит источник, покажет число добавляемых и заменяемых доменов и попросит подтвердить запись.
5. После подтверждения создаётся точная резервная копия; приложение заменяет записи доменов из списка Flowseal, сохраняя остальные записи и комментарии. Затем очищается DNS-кэш. Перезапустите браузер и проверьте сайты.

Hosts — системный файл сопоставления доменов и IP-адресов. Он находится в `%SystemRoot%\System32\drivers\etc\hosts`. Приложение использует тот же [источник Flowseal](https://raw.githubusercontent.com/Flowseal/zapret-discord-youtube/refs/heads/main/.service/hosts), что и оригинальный менеджер.

Новые записи находятся в блоке `# BEGIN Zapret Desktop (Flowseal)` / `# END Zapret Desktop (Flowseal)`. Повторное обновление заменяет этот блок, не создавая дубликатов. Совпадающие домены вне блока также обновляются, а остальные псевдонимы в тех же строках сохраняются.

## Как откатить

В разделе обновлений нажмите **«Восстановить hosts из копии»**. Автоматический откат возможен, пока hosts не менялся после последнего обновления. Если файл уже редактировала другая программа, автооткат остановится — новые правки не будут затёрты. Резервные копии лежат рядом с EXE в `data/backups`; путь к последней копии записан в журнале.

Если запись запрещена Windows или защитным ПО, приложение покажет ошибку. Оно не отключает защиту, не меняет разрешения файла и не снимает его атрибуты принудительно.

## IPSet

В том же разделе нажмите **«Обновить IPSet»** при остановленном Zapret. Скачивается официальный список IP/подсетей, проверяется его формат и сохраняется предыдущая версия. При выключенном фильтре обновляется сохранённый список, а выбранный режим фильтра остаётся прежним. Новая версия применяется после запуска/перезапуска обхода.

Если GitHub пока недоступен, в мастере можно выбрать **«Настроить обновления позже»**. После подключения через рабочую стратегию или другое соединение вернитесь к проверке. Мастер честно покажет, какие проверки не завершены.
