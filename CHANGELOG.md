# История изменений

## 1.0.0-rc.7 — 2026-11-02 · предварительный релиз

- README, инструкция, скриншоты на чистом встроенном наборе и публикация portable-релиза через GitHub Actions.
- Проверка приватности поставки, встроенные лицензии и отдельный архив соответствующих исходников WinDivert/Cygwin.
- Вся верхняя область списка стратегий, включая пустые отступы, закрывается кликом или свайпом вниз.
- Поле поиска сохраняет обычный ввод; потеря захвата мыши вложенным элементом не сбрасывает жест шапки.

## 1.0.0-rc.6 — 2026-11-02 · кандидат для проверки

- Отказ от установщика: отдельный EXE и ZIP с инструкциями/лицензиями.
- В мастере обязателен только набор Flowseal; проверки не запускаются при переходе между шагами.
- Уведомление о пропавшем или неполном наборе с повторным выбором папки.
- Во время подбора доступна только отмена; блокировка действует до очистки и восстановления подключения.
- Понятные подсказки, явные ошибки автозапуска, простые описания DNS и результатов.
- Финальная сборка ожидает проверки и одобрения пользователя.

## 1.0.0-rc.5 — 2026-11-02

- Исправлен заблокированный переключатель автозапуска, когда задача ещё не создана.
  Windows возвращает FileNotFoundException с HRESULT 0x80070002; это теперь состояние «выключен», а не ошибка доступа.
- Реальные ошибки чтения показываются рядом с переключателем, с кнопкой повторной проверки.
- Добавлена проверка чтения состояния реального Планировщика без изменения задач.

## 1.0.0-rc.4 — 2026-11-02

- По умолчанию профиль всех вариантов хранится в LocalAppData, без data рядом с EXE.
- Поддержан запуск одного EXE без внешнего config; настройки TLS/DPI и config для автозапуска встроены.
- Автоматический перенос старой data без удаления оригинала и без перезаписи существующего профиля.
- Кнопка «Папка данных» в настройках; переносимый профиль рядом с EXE доступен через portable.mode.
- Проверка единственного экземпляра выполняется до переноса данных и обновления автозапуска.

## 1.0.0-rc.3 — 2026-11-01

- Установщик Windows x64: Program Files, ярлыки рабочего стола/меню «Пуск», удаление через Windows.
- Профиль установленной версии в LocalAppData; необязательный перенос portable-данных.
- Обновление без перезаписи профиля; единый путь EXE для ярлыков и задачи автозапуска.
- Блокировка установки/удаления при работающем GUI; очистка собственных задач при удалении.
- Portable-архив сохранён. Добавлены сборка Setup.exe и контрольные суммы обоих вариантов.

## 1.0.0-rc.2 — 2026-11-01

- Автозапуск GUI через Планировщик с повышенными правами без повторного UAC при входе.
- Защищённая копия EXE/config в Program Files; настройки остаются в portable-папке.
- Перенос старого автозапуска из реестра после проверки задачи, откат при ошибке.
- Обновление защищённой копии после ручного запуска новой версии с UAC.
- Проверки XML, ACL, переноса и отката на подменённом Планировщике; проверка схемы
  встроенным валидатором Windows без создания задачи.

## 1.0.0-rc.1 — 2026-11-01

Первый релиз-кандидат для Windows x64.

- Нативный интерфейс WPF: тёмная тема, свой акцент, вертикальное окно, трей.
- Выбор набора Flowseal или встроенный набор 1.10.4; мастер первого запуска.
- Запуск стратегии и управление службой, игровой фильтр, IPSet и fake-пакеты.
- Проверка сети, перебор всех или выбранных стратегий, отмена и экспорт отчётов.
- Обновление hosts с предпросмотром, резервной копией и откатом.
- Выбор системного DNS over HTTPS, копии настроек и откат; необязательные шаги мастера.
- Диагностика, инструкции и результаты в общей теме интерфейса.
- Прокрутка мышью, свайпы панели стратегий, анимации переключателей.
- Исправлены отступы кнопок hosts/IPSet и сохранено правильное написание YouTube.
- Добавлены скрипт подготовки релиза, SHA-256, CI и документация для GitHub.

Системные операции требуют прав администратора. До стабильного 1.0.0 необходимо
пройти ручные проверки из RELEASE.md на обычной Windows; rc не заявляет полную
совместимость со всеми провайдерами, драйверами и политиками DNS.
